# ResolveIt - Complaint Resolution System

## Project Overview

ResolveIt is a Complaint Resolution System developed using Spring Boot and MySQL. It allows users to create, view, update, and delete complaints.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Features

- Add new complaints
- View all complaints
- Update complaint details
- Delete complaints
- Track complaint priority and status

## Backend

The backend provides REST APIs to handle complaint-related operations.

## How to Run

1. Clone this repository.
2. Import the project into Eclipse.
3. Configure the database settings in `application.properties`.
4. Run `ComplaintApplication.java`.
